# DIGITAL CRACKERS 🎆
### Interactive Virtual Fireworks Celebration Web Application

A beautiful, interactive, and responsive web application built with **React**, **Vite**, **HTML5 Canvas**, and **Web Audio API**. Experience the magic of festive fireworks in your browser with zero pollution and infinite joy!

---

## ✨ Features

- **Full-Screen Animated Night Sky**:
  - Cosmic navy, black, and purple gradient.
  - Twinkling stars with individual phase offsets.
  - Luminous glowing moon with corona halo and crater textures.
  - Drifting atmospheric cloud layers.

- **Realistic Fireworks Simulation Engine**:
  - Ascending rockets with glowing tails and exhaust spark particles.
  - Realistic physics (gravity, drag, acceleration, motion trails, and spark decay).
  - Sky flash illumination on explosion apex.
  - Secondary crackling chrysanthemum sparks.

- **Multiple Explosion Patterns**:
  - ⚪ **Circle Burst**: Classic spherical radial explosion with dense sparkling core.
  - ⭐ **Star Burst**: Crisp 5-pointed geometric star formation.
  - ❤️ **Heart-Shaped Fireworks**: Parametric cardioid curve creating romantic glowing hearts.
  - 🌀 **Spiral Burst**: 4-arm rotating Catherine wheel spiral with tangential velocity.
  - 🌈 **Rainbow Explosion**: Multi-ring concentric tiers in vibrant spectrum colors.
  - 🌾 **Golden Willow**: Weeping golden willow streamers that cascade down gracefully.

- **Vibrant Color Customization**:
  - Ruby Red, Sapphire Blue, Neon Pink, Mystic Purple, Emerald Green, Golden Glow, Cosmic Rainbow.

- **Celestial Floating Messages**:
  - Presets: *Happy Diwali!*, *Happy Birthday!*, *Happy New Year!*, *Congratulations!*, *Best Wishes!*, *I Love You!*.
  - Custom text input (up to 45 characters).
  - Customizable glowing colors (Gold, White, Cyan, Pink, Emerald, Amber, or match firework).
  - Floating celestial text banner with starlight glow and orbiting sparkles.

- **Interactive Controls & Glassmorphism UI**:
  - **Launch Firework**: Single hero firework.
  - **Launch Multiple**: Simultaneous 5-rocket barrage with wide spread.
  - **Surprise Mode**: Automated continuous firework display with randomized variations.
  - **Celebrate!**: Multi-wave grand finale ending cascade with celebration modal.
  - **Interactive Sky**: Click or tap anywhere on the night sky to launch fireworks directly to that spot!
  - **Sound Toggle**: Synthesized Web Audio API sound effects (rocket whistle, sub-bass boom, crackles, celestial chimes).
  - **Clear Sky**: Instantly clears sky particles.
  - **Fullscreen Toggle**: Immerse yourself in the virtual celebration.
  - **Minimizable Dock**: Collapse the control panel anytime for an unobstructed view of the night sky.

---

## 🛠️ Technology Stack

- **Frontend**: React 18 / 19, Vite 5 / 6
- **Graphics**: HTML5 Canvas API with additive blending (`lighter` composite operation)
- **Audio**: Web Audio API (100% synthesized; zero external audio files, works offline)
- **Styling**: Tailwind CSS + Glassmorphism UI
- **Icons**: Lucide React

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Run Locally

1. Navigate to the project directory:
   ```bash
   cd digital-crackers
   ```

2. Install dependencies (if not already installed):
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Open your browser at:
   ```
   http://localhost:3000
   ```

### Production Build

```bash
npm run build
```
The optimized production bundle will be generated in `dist/`.

## ☁️ Deployment

### Vercel
Simply connect the repository to Vercel. Framework preset: **Vite**. Build command: `npm run build`, Output directory: `dist`.

### Netlify
Build command: `npm run build`, Publish directory: `dist`.
